# Design System Notes

## Dashboard

- Static HTML first.
- Use restrained color: white panels, clear border, one main accent, one warning/accent color.
- Keep cards only for repeated items or compact tool panels.
- Use `letter-spacing: 0`.
- Avoid giant hero unless actual landing page requested.
- Mobile: single column, no overlapping text.

## PPT

- Start from strong existing deck when available.
- Make one visual hierarchy per slide: title, evidence, conclusion.
- Prefer fewer colors, strong alignment, consistent margins.
- Render preview PNG/PDF before final delivery.
- Keep fonts embedded or note required font files.

## QA

- Check desktop and mobile.
- Check long Korean labels.
- Check exported PPT/PDF rendering.
- Keep source and output versioned.

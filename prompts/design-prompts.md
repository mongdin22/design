# Design Prompts

## HTML Dashboard

Build a static Korean dashboard from the provided project notes. First screen must be the usable dashboard, not a landing page. Use compact cards, dense but readable information, restrained colors, no decorative gradient blobs, responsive layout, and no overlapping text. Include source/update metadata. Output as one `dashboard.html` unless a build system is already present.

## PPT Deck

Create a polished Korean PPT deck from the provided source material. Preserve factual order, reduce slide text, use strong hierarchy, consistent grid, and clear visual evidence. Reuse existing fonts/templates if provided. Export preview images or PDF and fix layout issues before final.

## Visual QA

Review the attached HTML/PPT/PDF visually. Find layout breaks, overflow, weak hierarchy, inconsistent spacing, poor contrast, missing source labels, and mobile issues. Return only actionable fixes with file/slide/page references.

## Asset Inventory

Scan the workspace for design-useful files: PPT/PPTX, HTML/CSS, fonts, SVG/PNG/JPG previews, design notes, prompts, skills, templates. Separate files to copy into Git from large files to reference by path. Preserve source paths.

# 영상의학과 발표 디자인 가이드

## 1. 공통 규칙

- 비율: 16:9 와이드스크린.
- 배경: `#FFFFFF`를 기본으로 사용하고, `#DBE8FE`를 섞은 연한 그라데이션을 장표마다 다른 방향과 형태로 배치한다.
- 컬러: 메인 포인트는 `#333ECB`, 보조 포인트는 `#818AFF`, 본문은 짙은 회색 계열을 사용한다.
- 제목 폰트: `한국기계연구원_Bold.ttf`의 `한국기계연구원_Bold`.
- 본문 폰트: `에이투지체-5Medium.otf`의 `A2Z 5 Medium` 또는 `에이투지체 5 Medium`.
- 폰트 적용: 제목과 소제목만 `한국기계연구원_Bold`, 그 외 본문·라벨·단계명·설명문은 모두 `A2Z 5 Medium`.
- 텍스트박스: 기본 배경은 투명으로 둔다. 강조 배경이 필요한 경우에만 의도적으로 연한 도형을 별도로 깐다.
- 텍스트 정렬: 모든 텍스트박스 속 텍스트는 세로 기준 가운데 정렬한다.
- 글머리 기호: 점과 텍스트가 별도 개체일 때는 점의 중심선을 해당 텍스트박스의 세로 중심선과 정확히 맞춘다.
- 화살표: 선과 화살표 머리는 같은 방향을 향해야 한다. 기본 삼각형 도형을 화살표 머리로 쓸 때는 선 방향에 맞게 회전시킨다.
- 스타일: 흰 여백을 넓게 두고, 얇은 선, 단순 아이콘, 도형 기반 도식으로 구성한다.
- 금지: 긴 줄글, 과한 카드형 레이아웃, 3D 도형, 진한 그림자, 불필요한 장식.
- 좌측 하단에는 발표 주제나 반복 footer를 넣지 않는다.

## 2. 문장과 정보량

- 한 장표는 한 가지 역할만 가진다.
- 본문 bullet은 최대 4개 이하로 제한한다.
- 설명 문장은 발표자 대본으로 이동하고, 화면에는 판단 기준과 키워드만 남긴다.
- 소제목과 도식 라벨은 문장형보다 명사형·핵심어형으로 쓴다.
  - 예: `CCLR 진단의 중심은 신체검사입니다` 대신 `CCLR 진단의 중심은 신체검사`.
- 화면 문구 말투는 발표문 말투를 쓰지 않고, 명사형·핵심어형으로 끝낸다.
  - 지양: `~입니다`, `~합니다`, `~보겠습니다`, `~중요합니다`.
  - 권장: `~임`, `~중심`, `~가능`, `~필요`, `~평가`, `~보조`, `~한계`.
  - 예: `방사선은 진단을 뒷받침합니다` 대신 `방사선은 진단 보완`.
- 의학 용어는 영문 약어와 한글 설명을 함께 쓰되, 한 줄 안에서 길어지면 분리한다.
- 치료, 예후, 수술법은 발표의 중심이 아니므로 진단 흐름을 보완하는 수준으로만 넣는다.

## 3. Slide 2. 발표 목표

### 역할

오늘 발표가 치료법 중심이 아니라 영상진단 접근 중심임을 선언하되, 임상증상·다른 진단법·치료 방향을 가볍게 연결한다.

### 화면 구성

- 좌측 상단에 작은 섹션 라벨 `02 목표`.
- 중앙 좌측에 큰 제목:
  - `오늘 볼 것은 진단명이 아니라, 영상에서 확인할 수 있는 소견`
- 제목 아래 짧은 소제목. 이 문구는 본문이 아니라 페이지 소제목으로 보고 `한국기계연구원_Bold`를 적용한다.
  - `정의 → 임상증상/검사 → 영상소견 → 치료 방향`
- 우측에는 4단 흐름 도식:
  - `질환 이해` → `임상진단` → `영상 판독` → `치료 방향`
  - 의미가 애매한 아이콘 대신 원형 숫자 `1`, `2`, `3`, `4`를 사용한다.
  - 단계 사이를 얇은 `#818AFF` 선으로 연결한다.
- 하단에는 작은 핵심 문장:
  - `핵심: 방사선에서 보이는 것과 보이지 않는 것을 구분`

### 배경과 색

- 우상단에서 좌하단으로 퍼지는 아주 연한 radial gradient 느낌을 만든다.
- 현재 강조 단계는 `#333ECB`, 나머지 보조 단계는 `#818AFF`로 처리한다.

### 발표자 대본

오늘 발표는 영상진단 관점에 맞춥니다. CCLR과 MPL이 어떤 질환인지 먼저 잡고, 임상증상과 신체검사, 영상 소견, 치료 방향을 진단 흐름 안에서 짧게 연결하겠습니다.

## 4. Slide 3. 정상 슬관절 해부

### 역할

CCLR과 MPL을 이해하기 위한 기준 구조를 제시한다.

### 화면 구성

- 좌측 상단에 작은 섹션 라벨 `03 해부`.
- 상단 제목:
  - `슬관절에서 봐야 할 구조는 CrCL, 경골, 대퇴골, 슬개골`
- 중앙 좌측에는 실제 이미지를 넣을 수 있는 회색 이미지 박스를 둔다.
  - 권장 이미지: 정상 canine stifle lateral radiograph.
  - 대안 이미지: 슬관절 해부도. CrCL, tibia, femur, patella 라벨이 명확한 자료.
  - 이미지가 준비되기 전에는 `이미지 삽입 위치`와 추천 이미지 조건만 짧게 적는다.
- 우측에는 구조별 짧은 라벨 4개:
  - `CrCL: 경골 전방 변위 억제`
  - `경골: 전방 변위 평가`
  - `슬개골: 활차구 내 주행`
  - `활차구: MPL 평가 기준`
- 하단에는 비교 연결 문장:
  - `CCLR = 안정성 문제 / MPL = 주행 문제`

### 배경과 색

- 좌하단에서 중앙으로 올라오는 사선형 `#DBE8FE → #FFFFFF` 그라데이션 느낌을 사용한다.
- 구조 강조는 1개만 진하게 한다. 이 장표에서는 CrCL을 `#333ECB`로 강조한다.

### 발표자 대본

CCLR은 전십자인대 안정성 문제이고, MPL은 슬개골 주행 문제입니다. 그래서 CCLR에서는 경골이 앞쪽으로 밀리는지, MPL에서는 슬개골이 활차구 안에 있는지를 기준으로 보게 됩니다.

## 5. 적용 메모

- 레퍼런스 1-5의 공통점 중 흰 여백, 파란 포인트, 단순 도형만 반영한다.
- 카드형 피치덱 느낌은 줄이고, 과제 발표용으로 정보가 읽히게 만든다.
- 같은 디자인 톤은 유지하되, 주제별로 슬라이드 순서와 도식 형태만 바꾼다.

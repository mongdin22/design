# Design Project Rules

- Answer primarily in Korean unless user asks another language.
- Keep design output practical: actual dashboard, deck, page, or asset first.
- For PPT work: preserve source deck, create versioned output, render or preview before final.
- For HTML dashboard work: static first, responsive, readable on laptop and phone.
- Avoid sensitive runtime files, caches, `node_modules`, and large generated temp outputs in Git.
- Put reusable prompts in `prompts/`, skills in `skills/`, references in `references/`, fonts in `assets/fonts/`.
- When adding external or copied assets, note source path in `inventory/design-sources.md`.
